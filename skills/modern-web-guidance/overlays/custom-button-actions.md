In a React app, do not hand-write this control. Keep the shadcn `button` from the component map in `${CLAUDE_PLUGIN_ROOT}/kb/ui-components.md` with its `onClick`, and do not add a command registry. Use this guide's ARIA list as a check on our own controls: `aria-expanded` for a disclosure, `aria-pressed` for a toggle, `aria-haspopup` for a menu opener, `aria-disabled` where focus must stay. Use the native pattern below only on a page with no React (a static page, an artifact, generated HTML).
