In a React app, do not hand-write this control. Use the shadcn `dropdown-menu` and `context-menu` from the component map in `${CLAUDE_PLUGIN_ROOT}/kb/ui-components.md`. Use this guide's keyboard rules as acceptance tests: a keyboard open puts focus in the menu, Escape closes one level and returns focus to its trigger, Tab closes all menus. Adopt its rule for checkable items: the check mark shows for about 300 ms before the menu closes. Use the native pattern below only on a page with no React (a static page, an artifact, generated HTML).
