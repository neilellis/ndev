In a React app, do not hand-write this control. Use the shadcn `hover-card` from the component map in `${CLAUDE_PLUGIN_ROOT}/kb/ui-components.md`. Check that it opens on keyboard focus as well as on hover. Use the ARIA rules as checks: a link trigger gets `aria-describedby`, not `aria-expanded`; the card is a preview only; focus does not move into it. Do not use `popover="hint"`, `interestfor` or CSS anchor positioning in React. Use the native pattern below only on a page with no React (a static page, an artifact, generated HTML).
