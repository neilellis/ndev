Follow the system scheme by default. A visible toggle is optional; put it in a settings surface first. In a React app, use the theme toggle row of the component map in `${CLAUDE_PLUGIN_ROOT}/kb/ui-components.md` and bind it to the project's theme provider. The pre-paint script must read the same storage key as that provider. Do not add a second store. Use the stored-value rules ("system" removes the stored value; an OS change does not) and the `storage` event sync as checks.
