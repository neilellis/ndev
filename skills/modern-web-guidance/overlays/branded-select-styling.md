Do not use `appearance: base-select` in a React app. Use the shadcn `select` for a branded or rich list and the shadcn `native-select` on mobile and in long forms, from the component map in `${CLAUDE_PLUGIN_ROOT}/kb/ui-components.md`; the native select keeps the platform picker. Use the native pattern below only on a page with no React (a static page, an artifact, generated HTML). Add a fallback and a contrast check there.
