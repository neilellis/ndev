In a React app, do not hand-write this control. Use the shadcn `sonner` toast from the component map in `${CLAUDE_PLUGIN_ROOT}/kb/ui-components.md`. An action in a toast, undo included, must also be available on the page. Use as checks: the timer pauses while focus is in the toast, the dismiss button can take focus but does not take it when the toast appears, and the message is announced (with `ariaNotify()` or a live region that exists on page load). One action shows one toast, also under React StrictMode, and a loading toast always ends in success or error. Errors that need action stay on the page.
