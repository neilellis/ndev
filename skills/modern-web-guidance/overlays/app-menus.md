Use a menu bar only for an application command bar (File, Edit, View). Site navigation uses the navigation-menu or sidebar rows of the component map in `${CLAUDE_PLUGIN_ROOT}/kb/ui-components.md`. In a React app, use the shadcn `menubar` if the project's primitive family has one; otherwise write it as an own component with the `// Own component:` comment. Use this guide's usage limits and its verification list as the acceptance tests.
