In a React app, do not hand-write this control. Use the shadcn `navigation-menu` for a marketing top bar and the `sidebar` for app pages, from the component map in `${CLAUDE_PLUGIN_ROOT}/kb/ui-components.md`. On mobile, move the links into a `sheet`. Use one `nav` landmark at every width and `aria-current="page"` on the current link. Use the native pattern below only on a page with no React (a static page, an artifact, generated HTML).
