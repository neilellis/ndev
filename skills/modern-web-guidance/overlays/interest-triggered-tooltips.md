In a React app, do not hand-write this control. Use the shadcn `tooltip` and `hover-card` from the component map in `${CLAUDE_PLUGIN_ROOT}/kb/ui-components.md`. Use this guide's checks on them: a hint that repeats the trigger's name adds nothing; a trigger that does something else gets a description, not `aria-expanded`; the hint is dismissible, hoverable and persistent (WCAG 1.4.13); focus does not move into it. For longer help, use a toggletip: a shadcn `popover` on a labelled "?" button. Use the native pattern below only on a page with no React (a static page, an artifact, generated HTML).
