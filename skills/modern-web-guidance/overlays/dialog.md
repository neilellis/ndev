In a React app, do not hand-write this control. Use the shadcn `dialog`, or `alert-dialog` for a destructive confirmation, from the component map in `${CLAUDE_PLUGIN_ROOT}/kb/ui-components.md`. Do not change its focus and Escape handling; test them. Add this guide's scroll containment to the dialog content and overlay classes: `overscroll-behavior: contain`. Use its unsaved-changes guard and its rule to show the reason in `aria-describedby` when a close is blocked. Use the native pattern below only on a page with no React (a static page, an artifact, generated HTML).
