In a React app, do not hand-write this control. Use the shadcn `dialog`, `popover` and `sheet` with their `Trigger` components, from the component map in `${CLAUDE_PLUGIN_ROOT}/kb/ui-components.md`. Check them against this guide: focus returns to the trigger on close, Escape closes, a modal keeps focus inside. Use the native pattern below only on a page with no React (a static page, an artifact, generated HTML). A polyfill there is a new dependency: add it to `${CLAUDE_PLUGIN_ROOT}/kb/libraries.md` first.
