In a React app, do not hand-write this control. Use the shadcn `breadcrumb` from the component map in `${CLAUDE_PLUGIN_ROOT}/kb/ui-components.md`. Our rule wins on one point: the last item is the current page with `aria-current="page"`, and it is not a link. Use the rest of this guide as checks: the separator is `aria-hidden`, the `nav` has an `aria-label`, the trail is an `ol`, and the focus ring has 3:1 contrast. The shape snippets are optional and not the default style.
