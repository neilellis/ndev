In a React app, do not hand-write this control. Use the Dice UI `circular-progress` from the component map in `${CLAUDE_PLUGIN_ROOT}/kb/ui-components.md`. Check it: the value is exposed to assistive technology, `aria-valuetext` is set when the centre shows another form of the value, the centre text is `aria-hidden`, and a change is instant under reduced motion. Use the success token, not a hard-coded colour.
