# Analyse complex source material

Save `analysis.md` when the material warrants a separate analysis. Record the message, audience, source language, intended display size and user design constraints. Identify the relationships the image must communicate before choosing a style.

| Structure | Candidate layouts |
|---|---|
| Sequence or process | linear-progression, winding-roadmap |
| Comparison | binary-comparison, comparison-matrix |
| Hierarchy | hierarchical-layers, tree-branching |
| Relationships | hub-spoke, venn-diagram, jigsaw |
| Metrics or categories | dashboard, periodic-table |
| Cycles | circular-flow |
| Spatial coverage | choropleth-atlas |
| Overview or detailed guide | bento-grid, dense-modules |

Keep a source ledger for numerical values, units, dates, names, quotation attribution and qualifiers. Do not round, remove uncertainty or infer missing values without an explicit basis. Shorten prose labels without strengthening their claims. Quoted wording remains exact and within applicable quotation limits.

Choose density for the intended viewing size: splitting a crowded image may communicate more than adding small text. Record the chosen layout/style and the visual role of each fact, such as a comparison, connection, highlighted number or sequence step.
