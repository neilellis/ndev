# Structured infographic content

For a complex image, save `structured-content.md` with these fields. Omit fields that add no value.

- **Title and message:** what the viewer must understand.
- **Audience and format:** knowledge level, language, intended size and aspect.
- **Sections:** for each, record its key idea, supporting source facts, intended visual element and exact on-image labels.
- **Source ledger:** numerical values with units and scope, names, dates and any attributed quotes. Preserve meaning and distinguish source facts from design directions.
- **Design directions:** layout, style, palette, references and user constraints.

Use a table for comparable items, ordered steps for a process, explicit levels for a hierarchy, and value/context/benchmark fields for metrics. Do not force the content into a layout that changes the relationship it describes.

Before rendering, check every intended label against the source ledger and ensure important qualifiers will remain legible. Concise paraphrases are acceptable; invented facts and unattributed or altered quotations are not.
