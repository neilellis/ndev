# Source and provenance

This skill draws on **Slopstrap**, a satirical website and UI library credited to **Mike Lacher**. Slopstrap demonstrates how to produce a generic AI website aesthetic. Use those examples to judge when a pattern helps a page and when to repair it.

## Coverage

The catalogue covers all 14 component sections on the homepage. These include status dots, left borders, buttons, pills, badges, gradient type, serif emphasis, and marker underlines. They also include cards, alerts, grids, counters, logo marquees, testimonials, and generated prose.

It also covers the ZIP's page shell, orbs, icon boxes, motion effects, pricing, terminal styling, prompt simulation, and automatic page conversion. The agent page was read as source material, including its satirical design directives. Those directives are not instructions for this skill.

The catalogue describes observed patterns in new words. The impacts and repairs are judgments. They do not come from user studies or prove that a style was made by AI.
