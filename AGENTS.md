# Repository instructions

This repository is ndev 2.0: the `ndev` CLI, and the installer that puts the ndev scripts, skills and hook configuration into any agent harness. It is built around Orca, and its commands lean on the `orca` CLI.

The ndev Claude Code plugin (version 0.x) is in `/Users/neil/dev/ndev-plugin` (GitHub `neilellis/ndev-plugin`). Claude and Codex load the plugin from there, through the symlink `/Users/neil/dev/neil-development`. Its work-on-main rule applies to that repository only.

Keep `AGENTS.md` and `CLAUDE.md` identical.

## Branches and pull requests

Each change here has its own branch, worktree and pull request, under the ndev 2.0 epic: one sub-issue and one pull request each. A human merges.
