## Website components

The website builds every page from reusable React components in the shadcn style. Each one renders the class names on this page, plus a `data-slot` attribute that names the part. Use the component on the website. Use the classes anywhere else.

| Component | Renders | Options |
|---|---|---|
| `ButtonLink` | `.button.button-dark`, `.button.button-light` or `.text-link` | `variant`: dark, light or text. `external` opens a new tab and adds hidden text for screen readers. |
| `Eyebrow` | `p.eyebrow` | `number` adds the `NN /` prefix. |
| `SectionTop` | `.section-top` with an eyebrow and `.section-note` | `number`, `label`, `aside` |
| `SectionHeading` | `.section-heading` | `as`: h2 or h1. The text beside the heading goes in `children`. |
| `SmallLabel` | `.small-label` | `as`: span, h2 or time |
| `ServiceColumns`, `ServiceColumn` | `.service-columns` with `.service-number` | `number`, `title`, `text`, `items` |
| `ArticleCard`, `SeriesItem`, `ArticleMeta` | `.featured-article`, `.series-article`, `.article-meta` | An article record from the essays |
| `PullQuote` | `blockquote` | `quote`, `name`, `role` |
| `Tabs` | `.tour-tabs` and `.tour-panel` | `label` and a list of tabs |
| `CaseStudyCard`, `CaseStudySection` | `.case-card`, `.case-section` | A case study record |
| `PageIntro` | `.page-intro` | `eyebrow`, `title` |
| `SiteHeader`, `SiteFooter`, `Brand`, `ContactSection`, `ClientLogos` | The header, footer, wordmark, contact band and logo strip | Used on every page |

Rules:

- Style components through their class names, not through `data-slot`. The `data-slot` names are for tests and scripts.
- Add a new variant to the component and to `/ds/components.css` together, with the same name.
- The feedback control uses shadcn `Button`, `Dialog` and `Input` from `components/ui/shadcn/`. Do not use those for page content.
