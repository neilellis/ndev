## Use the stylesheet

The whole system is one stylesheet. Link it, wrap your content in `.ds`, and use the class names shown on these pages.

```html
<link rel="stylesheet" href="/ds/styles.css">
<div class="ds">
  <p class="eyebrow"><span>01 /</span>Our services</p>
  <h2>People, technology and <em>the work between them.</em></h2>
</div>
```

The tokens live in `/ds/tokens/` as plain CSS custom properties. Fonts and logo files are in `/ds/assets/`.
