## The specification

| | |
|---|---|
| Frame | 1920×1080, 30fps |
| Length | About 64s of narration, a 30s silent end-card hold, then an 8s credits page (102.5s in the current cut) |
| File | H.264 MP4, CRF 18, `yuv420p`, `+faststart`, AAC narration |
| Loudness | About −16dB mean, no clipping |
| Sound | Narration only. No music bed in the current cut |
| Captions | Burned in. The film must work with the sound off |
| Audience | Prospective corporate clients |

## How it is made

1. **Script.** One line of narration per scene in `scripts/vo.json`, with the on-screen headline and look described in `script.md`.
2. **Voice.** Each line is spoken by OpenAI text-to-speech and transcribed by Whisper for word timings.
3. **Timeline.** Clip lengths, a tempo adjustment and fixed gaps give every scene a start and length, every word a time and every caption a slot.
4. **Scenes.** Each scene is an HTML section styled with the brand tokens. Elements appear when the narrator says a given word.
5. **Render.** A headless browser seeks to each frame's time, takes a screenshot, and FFmpeg encodes the frames with the audio.
6. **Review.** Stills at 85% of each scene, a contact sheet, then the MP4 itself. See the [review checklist](/video/review).
