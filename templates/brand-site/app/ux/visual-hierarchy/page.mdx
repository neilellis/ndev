# Visual hierarchy

Visual hierarchy tells the reader where to look first, second and last. The {{name}} website is flat, so it uses size, colour, space and order. It does not use shadows.

<Rule>
The website values on this page come from `{{source}}/public/styles.css`. The reading-pattern guidance is a recommendation.
</Rule>

## The four tools

| Tool | How the website uses it |
|---|---|
| Size | Display headings are very large (the hero is 70–105px). Body text is 18px. The gap between them makes the order clear. |
| Colour | Navy ink for text. Blue only for the accent phrase, links on hover and the eyebrow number. Spend the blue on one thing. |
| Space | 90px section padding. A heading with space around it reads as more important than a crowded one. |
| Order | The eyebrow, then the heading, then the intro, then one action. |

## One focal point per view

- Use the [signature move](/core-principles) once per view: a plain statement, then a blue serif italic phrase.
- Use one dark button per view. Make the other actions text links.
- Do not give two items the same weight. If two things compete, make one smaller or quieter.

## Separate with rules, not boxes

The website separates content with 1px hairline rules and tinted bands. A box or a shadow adds weight that competes with the content. Shadows are only for things that float above the page. See [Depth and motion](/foundations/depth-motion).

## Reading patterns

- **Text pages.** The eye scans across the top line, then down the left edge. Put the key word at the start of the line.
- **Sparse sections.** The eye moves from top left to top right, then to the bottom. The website puts the wordmark top left and “Let’s talk” top right.
- **Phones.** There is one column, so the reader goes from top to bottom. Hierarchy comes from order, size and space only.

## Group items

Keep lists short or put them into groups. The service columns show three groups of three to five items. Each group has a number, a heading and a short line of text.
